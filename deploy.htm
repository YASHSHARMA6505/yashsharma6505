# NER-SAFE production deployment
2+
3+
NER-SAFE is a **real-time landslide risk and early-warning prototype**.
4+
It is **not** an officially authorized government warning system.
5+
6+
Local development on Windows continues to use SQLite (`data/nersafe.db`) and `python app.py`.
7+
Ubuntu production uses PostgreSQL (PostGIS when available), Gunicorn, systemd, and Nginx.
8+
9+
Use **one Gunicorn worker**. The live-rainfall scheduler and alert reminders run inside that process.
10+
11+
## 1. Server packages
12+
13+
```bash
14+
sudo apt update
15+
sudo apt install -y python3 python3-venv python3-pip python3-dev \
16+
postgresql postgresql-contrib postgis postgresql-14-postgis-3 \
17+
nginx certbot python3-certbot-nginx git
18+
```
19+
20+
If your Ubuntu PostgreSQL major version is not 14, install the matching `postgresql-XX-postgis-3` package.
21+
22+
## 2. Application user and files
23+
24+
```bash
25+
sudo useradd --system --home /opt/nersafe --shell /usr/sbin/nologin nersafe
26+
sudo mkdir -p /opt/nersafe
27+
sudo git clone <YOUR_REPO_URL> /opt/nersafe
28+
# or copy the project tree to /opt/nersafe
29+
sudo chown -R nersafe:nersafe /opt/nersafe
30+
```
31+
32+
## 3. Python environment
33+
34+
```bash
35+
sudo -u nersafe python3 -m venv /opt/nersafe/.venv
36+
sudo -u nersafe /opt/nersafe/.venv/bin/pip install -U pip
37+
sudo -u nersafe /opt/nersafe/.venv/bin/pip install -r /opt/nersafe/backend/requirements.txt
38+
```
39+
40+
Place the trained model at `/opt/nersafe/model/landslide_model.pkl` (do not train on the public server unless you intend to).
41+
42+
## 4. Environment file
43+
44+
```bash

48+

49+

50+

Set at least:

57+
PUBLIC_BASE_URL=https://nersafe.example.org
58+
ENABLE_SCHEDULER=1
59+
```
60+
61+
Generate a secret:
62+
63+
```bash

python3 -c "import secrets; print(secrets.token_urlsafe(48))"
65+
```

## 5. PostgreSQL + PostGIS
68+
69+
```bash
70+
sudo -u postgres psql <<'SQL'
71+
CREATE USER nersafe WITH PASSWORD 'STRONG_PASSWORD';
72+
CREATE DATABASE nersafe OWNER nersafe;
73+
\c nersafe
74+
CREATE EXTENSION IF NOT EXISTS postgis;
75+
GRANT ALL ON SCHEMA public TO nersafe;
76+
SQL
77+
```
78+
79+
Apply the application schema (also created automatically on first app start):
80+
81+
```bash
82+
sudo -u postgres psql -d nersafe -f /opt/nersafe/deploy/schema.sql
83+
```
84+
85+
Tables created: `users`, `roles`, `user_roles`, `locations`, `rainfall_observations`, `predictions`, `model_versions`, `alerts`, `audit_logs`, plus GIS cache, deliveries, and `system_jobs`.
86+
87+
If PostGIS is installed, the app adds a `locations.geom` point column on startup. Latitude/longitude columns remain the source of truth for the existing Flask queries.
88+
89+
## 6. Gunicorn + systemd
90+
91+
```bash
92+

93+
sudo systemctl daemon-reload
94+

95+
sudo systemctl status nersafe
96+

97+
98+
The unit runs:

102+
```
103+
104+
`wsgi.py` starts the rainfall (every 3 hours) and alert-reminder (every 30 minutes) jobs when `ENABLE_SCHEDULER=1`.

## 11. Health checks
161+
162+
| URL | Purpose |
163+
|---|---|
164+
| `GET /health` | Process liveness |
165+
| `GET /api/health` | Database ping, rainfall freshness, job status, last prediction, stale-data flag |
166+
167+
`/api/health` returns HTTP 503 if the database is unreachable. Stale rainfall is reported as `"status": "degraded"` with `"rainfall.stale": true` while the process stays up.
168+
169+
Production logs are JSON lines on stdout (journald):
170+
171+
```bash
172+
sudo journalctl -u nersafe -f
173+
```
